# Image Gallery

黒基調の画像ギャラリーです。スマートフォン・PCに対応し、画像の拡大表示、個別ダウンロード、ZIP一括ダウンロードができます。

## 使い方

1. `images` フォルダに掲載したい画像を3枚入れます。
2. ファイル名を `photo1.jpg`、`photo2.jpg`、`photo3.jpg` にするか、`script.js` の `images` 配列に合わせてファイル名を書き換えます。
3. `index.html` をブラウザで開いて表示を確認します。

## 画像の差し替え

`script.js` の冒頭にある配列を編集します。

例：
```js
const images = [
  { title: "写真タイトル", path: "images/好きな名前.png", filename: "好きな名前.png" },
  { title: "2枚目", path: "images/second.webp", filename: "second.webp" }
];
```

- `title`: ページ上に表示する名前
- `path`: imagesフォルダからの画像ファイルの場所
- `filename`: ダウンロード時のファイル名

画像を追加する場合は、配列に同じ形式の行を追加してください。

## QRコードで公開するには

QRコードからアクセスさせるには、このフォルダ一式をWebホスティングサービスに公開し、公開後に発行される `https://...` のページURLでQRコードを作成します。PC内のファイルパスや `file://` のURLでは、他の人はアクセスできません。

## 注意

- ZIP一括ダウンロードにはインターネット接続が必要です（JSZipをCDNから読み込みます）。
- ダウンロード処理は、Webサイト上で配信している画像を想定しています。ブラウザで直接 `index.html` を開く方法では、ブラウザの制限によりダウンロードや画像取得が正常に動作しない場合があります。公開前の確認にはローカルWebサーバーを使ってください。
- このページにアクセスできる人は、掲載画像を閲覧・保存できる前提で公開してください。
